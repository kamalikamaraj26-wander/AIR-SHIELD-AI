How to connect your ESP32

POST a JSON reading to /api/readings. If DEVICE_TOKEN is configured, include the X-Device-Token header.

{
  "device_id": "indoor_01",
  "pm25_ugm3": 12.4,
  "temperature_c": 27.1,
  "humidity_pct": 62,
  "source_type": "sensor",
  "quality_flag": "valid"
}

Keep the API token private. Do not expose an unauthenticated write endpoint to the public internet.
